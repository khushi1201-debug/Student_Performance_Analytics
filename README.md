Student Performance Analytics System


1. Project Overview
The Student Performance Analytics System is a Python-based project that analyses student marks and attendance. It calculates total marks, average marks, grades, pass/fail results, subject-wise performance, and identifies the top-performing students.

2. Objective
The main objective of this project is to analyse student academic performance using Python, NumPy, and Pandas and present meaningful information about student results.

3. Technologies Used
Python
NumPy
Pandas
CSV dataset
Visual Studio Code

4. Dataset Description
The dataset contains 20 student records.
The columns include:
Student ID
Name
Department
Python marks
SQL marks
Statistics marks
Attendance

5. Features
Reads student data from a CSV file.
Calculates total marks for each student.
Calculates average marks.
Assigns grades based on average marks.
Identifies pass/fail students.
Calculates the overall class average.
Finds the highest and lowest student averages.
Performs subject-wise performance analysis.
Displays the top five students.
Exports the final results to a CSV file.
